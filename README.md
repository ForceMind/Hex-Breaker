# 🎮 瓦片破坏者 Hex Breaker

一款 H5 无尽街机射击游戏：八边形瓦片从顶部不断流下，左右移动躲避并自动射击，靠武器、炸弹、道具与动态难度撑到更高等级。基于 **Phaser 3 + TypeScript + Vite** 构建。

## 🌟 游戏特色

- **八边形瓦片**：带堆叠厚度视觉的立体瓦片，厚度即血量（烘焙贴图按 1–8 层分层渲染）
- **5 种武器多持升级**：默认弹 + 冲锋枪 / 霰弹枪 / 激光炮 / 散射枪，可同时持有、各自升到 Lv5
- **5 种炸弹**：普通 / 大型 / 斜射 / 横向 / 线性，各有射程、范围与伤害
- **智能回旋镖**：弧线飞出，击杀后直线穿透，返程可接住重新抛出
- **20 种道具**：武器、炸弹、护盾、回旋镖与 9 种永久增益，L15 前随等级逐步解锁
- **战力动态难度**：按武器与增益实时计算战力，驱动瓦片密度 / 血量 / 流速，难度分「简单 → 稍难 → 中等 → 困难 → 地狱」五档
- **13 种行阵型**：L3 起出现走廊 / 墙壁 / 菱形 / 波浪 / 隧道 等阵型（见下文阵型表）
- **3 命制**：被撞扣命并短暂无敌，生命上限 9
- **最高分本地存档**：最高分、最高等级、累计统计写入 localStorage
- **BOSS 关**：战役第 10 / 20 / 30 关，顶部漂移的大号 BOSS + 护卫瓦片波次，血条取代目标进度
- **金币经济**：通关 / 每日 / 无尽结算产出金币，胜利与结束面板显示入账，主页右上角金币徽章
- **8 套皮肤主题（角色 + 配套背景）**：天空（拿枪小兵，默认）/ 宇宙（飞船）/ 森林（弓箭游侠）/ 落日（牛仔）/ 海洋（潜水员）/ 霓虹（未来特工）/ 雪地（狙击手）/ 熔岩（战士），金币解锁，切换后角色形象与全场景配色同时生效
- **模拟周榜**：无尽模式本周排行榜，100 名模拟玩家由周种子幂律生成，每周自动重置
- **道具按皮肤换肤**：8 主题 × 20 道具独立名称（脉冲机炮 / 连珠弩 / 双持左轮 / 泡泡机关枪……），名称与盒体描边随皮肤变化
- **AI 砖块与背景**：每主题独立砖块顶面与竖版背景图，缺失时完整回退程序渲染
- **PWA 可安装**：manifest + Service Worker 离线壳，iOS「添加到主屏幕」引导 / Android 原生安装提示
- **合成音效 + 震动**：全部音效用 Web Audio 实时合成（无任何音频文件），移动端支持震动反馈
- **PC / 移动端双适配**：PC 宽屏下呈现居中圆角「手机框」竖屏卡片，移动端全屏沉浸

## 🚀 快速开始

环境要求：**Node.js ≥ 20**

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（默认 http://localhost:5173）
```

其他常用命令：

```bash
npm run build      # 类型检查 + 产物构建到 dist/

npm test           # 运行 vitest（11 个测试文件，121 个用例）
npm run typecheck  # 仅运行 TypeScript 类型检查
```

## 🎮 玩法与数值

> 以下数值全部来自 `src/core/config.ts`、`src/core/difficulty.ts`、`src/core/patterns.ts`，改动玩法请先改这三处。所有「帧」按 60 fps 计（1 帧 = 1/60 s）。

### 基础规则

- 摧毁 1 块瓦片得 1 分；每 **8 分升 1 级**，每级游戏速度 +0.09
- 开局 4 行瓦片，初始血量在 [1, 2] 内随机；瓦片边长 50，行距 55
- 玩家 40×40，移动速度 5 px/帧，距屏幕底边 60 px
- 初始 3 条命，上限 9；被撞后获得 120 帧（2 秒）临时护盾无敌
- 护盾持续 300 帧（5 秒），强化护盾 600 帧（10 秒）

### 武器系统

5 种武器可同时持有，各自独立升级（最高 Lv5）。特殊武器为限时武器，持续帧数 = `(600 + 等级×60 + 武器加成) × 持久增益`（加成：冲锋枪 0、霰弹枪 60、激光炮 120、散射枪 90）。

每轮齐射间隔（帧）：

| 武器 | 基础冷却公式 | Lv1 | Lv5 |
| --- | --- | --- | --- |
| 默认 | 17 | 17 | 17 |
| 冲锋枪 | max(3, 8 − Lv) | 7 | 3 |
| 霰弹枪 | max(25, 40 − 2×Lv) | 38 | 30 |
| 激光炮 | max(35, 50 − 3×Lv) | 47 | 35 |
| 散射枪 | max(12, 25 − 2×Lv) | 23 | 15 |

「连射」增益使冷却减半（向下取整），任意两轮齐射之间全局最小间隔 3 帧。子弹速度 8 px/帧（激光 12），半径：普通 4 / 激光 6 / 小弹 3 / 大弹 8；激光伤害 3；「穿透」增益下单发最多命中 3 个目标。

### 炸弹系统

| 类型 | 速度 | 爆炸半径 | 基础伤害 | 说明 |
| --- | --- | --- | --- | --- |
| 普通炸弹 | 6 | 80 | 4 | 垂直向上 |
| 大型炸弹 | 5 | 120 | 8 | 范围与威力更大 |
| 斜射炸弹 | 7 | 70 | 4 | 斜 45°，发射时随机选左右 |
| 横向炸弹 | 6 | 60 | 4 | 水平方向，随机选左右 |
| 线性炸弹 | 8 | 40 | 6 | 命中横向 ±30 px 内的整列瓦片 |

爆炸动画 20 帧，单块瓦片保底伤害 2。

### 回旋镖

速度 6，半径 15，最长飞行 120 帧；弧高 120、弧宽 150，伤害 2；返程速度 ×1.5，距玩家 30 px 内可接住重新抛出。

### 道具与解锁

瓦片被摧毁时的掉率 = `min(0.22, 0.055 + 0.015×等级)`。道具按等级分批进入掉落池：

| 解锁等级 | 新增道具 |
| --- | --- |
| L1 | 冲锋枪、炸弹、护盾 |
| L3 | 霰弹枪、回旋镖 |
| L5 | 激光炮、大炸弹 |
| L7 | 散射枪、斜炸弹、横炸弹 |
| L9 | 线炸弹、加速 |
| L11 | 双子弹、连射 |
| L13 | 穿透、磁力、大弹 |
| L15 | 护盾+、持久、生命 |

永久增益效果：双子弹（每次双发）、连射（冷却减半）、穿透（最多命中 3 目标）、磁力（拾取范围每层 +50 px）、大弹（子弹尺寸每层 +2，上限 +8，满后从掉落池移除）、加速（移动速度每层 +2）、持久（武器时长每层 +50%）、护盾+（强化护盾 10 秒）、生命（+1，上限 9）。

### 动态难度

战力 `power` 由当前武器与永久增益计算：基础 1；每种激活特殊武器加 `等级 × 系数`（冲锋枪 1.2、霰弹枪 1.5、激光炮 1.8、散射枪 1.3）；双子弹 +2、连射 +1.5、穿透 +1.3；大弹每层 +0.3、加速每层 +0.2；多持奖励 = 激活特殊武器数 × 0.5。

| 公式 | 说明 |
| --- | --- |
| 密度 = min(0.90, 0.62 + min(power/12, 0.22) + min(等级/24, 0.16)) | 每行生成瓦片的概率，封顶 0.90 |
| 血量区间 = [⌊等级/3⌋, 等级+2] × max(0.8, power/9)，封顶 40 | 取下整；上限封顶后下限自动收拢 |
| 下落速度 = 游戏速度 × 0.42 × min(1.4, 1 + (power−1)/15) | 每帧下落像素 |
| 难度档位 | power < 5 简单 / ≥5 稍难 / ≥8 中等 / ≥12 困难 / ≥15 地狱 |

### 行阵型

L3 起，新行有 80% 概率采用 13 种阵型之一（否则为「传统」满行）：

走廊、墙壁、中央、两侧、间隙、之字、菱形、波浪、隧道、阶梯、十字、随机、障碍。

## 🛠️ 技术栈与架构

- **Phaser 3**：渲染与场景管理（`Phaser.AUTO`，FIT 缩放，DPR 封顶 2）
- **TypeScript**：严格类型，`tsc --noEmit` 全量检查
- **Vite**：开发与构建；`BASE_PATH` 环境变量控制部署 base 路径
- **Vitest**：核心数值层单元测试（node 环境）
- **无资源文件**：所有贴图由 Graphics API 以 2 倍尺寸程序烘焙（白色底图 + `setTint` 上色），所有音效由 Web Audio 实时合成

设计分辨率宽 540，高 960–1200（随视口宽高比自适应）；PC 宽屏（宽高比 ≥ 3/4）时画布居中显示为带圆角和投影的竖屏「手机框」，移动端全屏。

## 📲 安装到主屏（PWA）

游戏是完整 PWA：部署到 HTTPS 后即可「安装」到手机主屏，离线可玩。

- **Android（Chrome/Edge/三星浏览器）**：设置页点「安装到主屏」触发系统安装弹窗；第二次回到主页也会自动邀请一次（仅一次）。
- **iOS（Safari）**：系统无安装 API，按引导手动操作——分享 → 添加到主屏幕。
- 微信 / QQ / UC 等内嵌浏览器与已安装的 standalone 模式不会收到任何安装提示。
- Service Worker 策略：`/assets/` 下带内容 hash 的 JS/CSS 为 cache-first；页面、manifest 与 AI 素材为 network-first + 缓存兜底；缓存名随版本号滚动，旧缓存自动清理。
